수정 결과

  1. 빈 프로젝트에서 A동·1층·2층과 Venue/Building/Level Geometry를 직접 만든다.
  2. PDF 페이지 선택과 정렬 결과 확인을 필수 경로로 연결했다.
  3. Unit Polygon, Opening LineString, 경계 확인을 분리하고 정상·오류 결과를 구분했다.
  4. 모든 문제 행을 해당 원인과 수정 방법 화면에 연결했다.
  5. 오류·경고·검토용·생성 실패 내보내기를 독립 상태로 분리했다.
  6. 도면 교체 후 Geometry 검토 문맥을 상세 화면까지 유지했다.
