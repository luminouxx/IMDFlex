오늘은 여러분을 평가하는 것이 아니라 제품을 평가합니다. 화면에서 무엇을 기대하는지, 왜 특정 항목을 선택하는지를 계속 말해주세요. 실제 데이터는 저장되거나 Apple에 제출되지 않습니다.

과업 시나리오

T1. 새 프로젝트와 공간 구조

HOME-01에서 시작
8분

“평면도를 등록할 수 있는 상태까지 전시장 프로젝트의 공간 구조를 준비해 주세요.”

성공: 새 프로젝트로 진입하고 주소·프로젝트 이름·A동·1층·2층과 각각의 공간 경계를 확인한 뒤 평면도 허브에 도달한다.

T2. 평면도 등록과 정렬

FLOOR-01P에서 시작
6분

“A동 1층 PDF를 등록하고, 지도와 정렬이 완료된 상태로 만들어 주세요.”

성공: 올바른 Level·PDF 페이지를 선택하고 Alignment Result를 적용한다.

T3. 공간과 출입구 작성

AUTHOR-01에서 시작
10분

“중앙 홀 옆에 새 공간을 만들고, 중앙 홀로 통하는 출입구까지 작성해 주세요.”

T3A Unit, T3B Opening, T3C 경계 오류를 독립 상태로 연다. T3C 오류 상태 · T3B 성공 종료

T4. 오류 수정과 재검사

REVIEW-01에서 시작
7분

“가장 먼저 처리해야 한다고 판단한 문제를 해결하고, 현재 남은 문제가 무엇인지 확인해 주세요.”

성공: 위치 확인 → 수정 시작 → Geometry 수정 → 재검사 → 해결 배너와 남은 문제를 이해한다.

T5. 내보내기 상태별 판단

EXPORT-01에서 시작
10분

오류 차단, 경고 확인, 검토용 ZIP, ZIP 실패를 각각 독립된 시작 상태로 제시한다. 상태 전환 시간은 제외한다.

성공: T5A 오류는 제출 차단, T5B 경고는 확인 후 진행, T5C 검토용은 제출용과 분리, T5D 실패는 재시도·위치 변경으로 복구한다.

T5A 차단 · T5B 경고 · T5C 검토용 · T5D 실패

T6. 도면 교체 후 작업 계속

FLOOR-07에서 시작
5분

“기존 작업을 보존하면서 새 도면으로 교체하고, 다음에 무엇을 검토해야 하는지 확인해 주세요.”

성공: 영향을 먼저 예측하고 교체 → 재정렬 → Review Required → 영향받은 Geometry 검토 화면까지 이동한다.
