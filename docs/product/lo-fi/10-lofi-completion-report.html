닫힌 핵심 흐름

새 프로젝트에서 ZIP까지

최근 프로젝트 → 시작 방식 → 프로젝트 기본 정보 → 주소·Venue·Building·Level → 평면도 등록·정렬 → 프로젝트 개요 → 지도 편집 → Feature·관계 작성 → 문제 확인·수정·재검사 → Preflight → ZIP 생성 → Apple Validator 안내 → 프로젝트 또는 버전 기록

문제 해결 반복

문제 목록 → 문제 선택 → 지도 위치와 설명 → 수정 시작 → Geometry 수정 → 재검사 ├─ 해결됨: 성공 배너 + 남은 문제 목록 ├─ 같은 문제: 기존 위치·설명 화면 └─ 오류 0: 내보내기 준비

논리 검증 규칙

  • 모든 화면은 이전, 취소, 완료, 다음 행동 중 하나 이상으로 나갈 수 있습니다.
  • 오류 화면은 원인, 영향받는 대상, 복구 행동을 제공합니다.
  • 데이터 손실 가능성이 있는 취소·삭제·복원은 확인 단계를 거칩니다.
  • Setup을 건너뛰어도 프로젝트 탐색은 가능하고 필요한 종속 작업만 차단합니다.
  • 제출 차단형 미완료와 Workflow 경고형 미완료를 구분합니다.
  • 앱 내부 검사만으로 Apple IMDF Validator 통과를 보장하지 않습니다.

UI 전수 검수 결과

  • 버튼, 목록, 검색, Form, 지도, Inspector, 상태 배너가 형태로 구분됩니다.
  • 현재 프로젝트·건물·층 맥락과 Primary·Secondary 행동이 구분됩니다.
  • Polygon, Line, Point, Opening, Vertex의 지도 표현을 확인했습니다.
  • 선택된 목록·PDF 페이지·Level·Category·Feature의 선택 상태를 보강했습니다.
  • Polygon 경계, Opening 표현, 잘린 Export 버튼과 과도한 제출 보장 문구를 수정했습니다.
  • 텍스트 잘림, 화면 경계 이탈, Placeholder, 누락 글꼴은 발견되지 않았습니다.

제품 결정

발견된 논리적 구멍 10개는 모두 D-LF-001~010으로 승인·반영했습니다. Draft Project, Drawing Draft, 제출 차단, Setup Skip, 계층 삭제, ZIP 취소, 도면 교체, 버전 복원, iCloud 충돌, IMDF Import 정책이 포함됩니다.

다음 단계

Lo-Fi 단계는 완료입니다. 다음 작업은 대표 과업을 실제 사용자에게 수행시키는 Task-based 사용성 테스트입니다. 테스트에서 발견된 문제는 Screen ID와 Decision ID로 추적해 수정합니다.
