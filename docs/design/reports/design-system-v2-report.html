레퍼런스 반영

iOS and iPadOS 27 Community 라이브러리를 연결해 Toolbar, Sidebar, Row, Button, Text Field, Segmented Control을 실제 인스턴스로 사용했습니다.

Astryx는 대상 Figma 파일에서 연결 가능한 라이브러리로 노출되지 않아 컴포넌트 구조와 시스템 원칙을 분석해 semantic token, 상태 계약, 테마, 문서화 방식에 반영했습니다.

Product Patterns 재설계

V2 · 20 Product Patterns를 지도 중심의 IMDF 저작 도구로 전면 교체했습니다. 실제 도로와 건물 맥락, 층 도면 오버레이, 선택된 Unit의 네 꼭짓점, Opening 위치, 짧은 스냅 가이드를 하나의 편집 상태로 연결했습니다.

Regular · 1440×960플로팅 Sidebar, 세로 Spatial Dock, Toolbar, Inspector를 모두 표시하는 Mac·대형 iPad 작업 공간
Intermediate · 1180×820탐색 구조를 축약하고 지도 가시 면적을 확보한 중간 폭 편집 공간
Compact · 768×1024Sidebar를 제거하고 가로 도구 Dock과 바텀 시트 Inspector로 전환한 iPad형 편집 공간
  • Select, Point, Unit, Opening, Locate를 서로 다른 공간 편집 아이콘으로 교체
  • 중복된 Level 정보 구조를 정리하고 Sidebar를 2단계 이내로 단순화
  • 3개의 차단 이슈가 있으면 Export IMDF를 비활성화해 상태 모순 제거
  • 선택 상태와 오류의 원인을 지도 형상으로 바로 추적할 수 있도록 연결

Mapbox Studio의 레이어·지도·도구 구조, Felt의 선택 기반 상세 패널, ArcGIS Map Viewer의 Contents·Settings 분리, Apple의 Sidebar와 Liquid Glass 원칙을 제품 구조에 맞게 조합했습니다.

접근성 및 품질 기준

  • Accent 대비 최소 6.63:1, Status 대비 최소 4.85:1
  • 모든 인터랙티브 터치 영역 최소 44pt
  • Light, Dark, Light High Contrast, Dark High Contrast 지원
  • Default부터 AX5까지 Dynamic Type 검증 표본 제공
  • Standard와 Reduced Motion 모드 지원
  • 로딩 상태 전환 시 버튼 크기 변화 없음
  • 축소 사이드바에서 행과 액세서리 오버플로 없음

검수 결과

iOS 기준, Astryx 시스템 기준, 제품 구조 기준을 맡은 세 검수 에이전트가 수정된 실제 Figma 노드를 다시 측정했고 모두 GO로 판정했습니다.

Product Patterns 최종 검사에서 UI 텍스트 스타일 누락 0건, 44pt 미만 액션 영역 0건, 상태 문구 모순 0건, 잔존 레거시 패턴 0건을 확인했습니다.

Figma 자동화 환경에서 새 SF Pro 텍스트 렌더링이 제한되어 미리보기에는 Inter를 사용했습니다. 각 스타일에는 Apple semantic typography 역할이 기록되어 있어 추후 SwiftUI에서는 시스템 San Francisco 글꼴로 매핑할 수 있습니다.

정리된 이전 자료

기존 Hi-Fi 디자인 시스템 페이지, 레거시 변수 컬렉션, 레거시 텍스트 스타일은 제거했습니다. 작업 흐름 검토에 필요한 초기 Wireflow와 Lo-Fi 화면은 유지했습니다.
