공용 API

IMDFButtonStyle

primary · secondary · destructive. 44 pt, pressed, disabled, Reduced Motion 처리.

IMDFField

Label, 44 pt field, focus, supporting text, error, icon, disabled, read-only. Binding과 title만 필수.

IMDFStatusBadge

32 pt display status. 색상만 쓰지 않고 역할별 SF Symbol과 접근성 value 제공.

IMDFToolButton

44×44 icon control. 선택과 실행 가능 상태를 서로 다른 의미로 분리.

IMDFPanel

순수 surface container. floating · inspector · status 스타일은 scoped Environment.

Inspector rows

32 pt 표시 행과 44 pt action 행을 분리해 터치 영역 의미를 보존.

IMDFDisclosureSection

native DisclosureGroup을 사용. 언제 펼칠지는 Presentation이 결정.

IMDFSelectionButton

title/action만 필수. subtitle, icon, selected는 focused modifier.

Button("Create feature", systemImage: "plus", action: createFeature)
    .buttonStyle(.imdfPrimary)

IMDFField("Name", text: $name)
    .placeholder("Feature name")
    .supportingText("Shown to map users")

IMDFToolButton("Unit", systemImage: "square.split.2x2", action: selectUnit)
    .selected(selectedFeature == .unit)
